## Security/Bug Fixes
Security and bug fixes are generally only provided for the last minor version. Fixes are released as part of the next minor version.

Security fixes are given priority and might be enough to cause a new version to be released

## Reporting a Vulnerability

Responsible disclosure of security vulnerabilities are encouraged. Vulnerabilities should not be discussed with anyone outside of team or on public forums

In order for the vulnerability reports to reach maintainers as soon as possible, the preferred way is to use the "Report a vulnerability" button under the "Security" tab of the associated GitHub project. 
This creates a private communication channel between the reporter and the maintainers.
Please include the requested information listed below to help us better understand the nature and scope of the issue:
  * Type of issue if know
  * Full path of the source file/s related to the manifestation of the issue
  * Location of the effected source code
  * Any configuration required to reproduce issue
  * Step by step guide on how to reproduce issue
  * Impact of the issue

This information will help us triage your report more quickly.
